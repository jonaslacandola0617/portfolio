## Overview

Most portfolio templates for a networking/security background end up looking like a generic
developer site with the word "cybersecurity" added to the hero. I wanted something that reads
more like the tools I actually use every day — documentation sites, lab notebooks, changelogs —
because that's the muscle this field actually exercises: writing things down clearly enough that
someone else (or future me) can follow them.

## Objectives

- Build a documentation-style layout: persistent sidebar, docs-style content column, table of contents
- Drive every project, lab, and journal entry from MDX so adding content never means touching layout code
- Keep the palette disciplined — slate + a single blue accent, no neon, no "hacker" clichés
- Make it fast, accessible, and keyboard-navigable by default

## Technologies Used

Next.js App Router with static generation, TypeScript throughout, Tailwind CSS with a small
custom design-token layer, Radix primitives for accessible interactive components, and
`next-mdx-remote` with `rehype-pretty-code` for syntax-highlighted, component-aware MDX content.

## Lessons Learned

- Centralizing personal details (name, links, currently-learning list) in one config file made the
  site genuinely reusable instead of hard-coded
- A docs-style layout forces content discipline — there's nowhere to hide a vague project writeup
  behind a flashy hero image
- Building the "lab notebook" format for the Labs section made me more consistent about actually
  logging labs instead of only writing up the ones that went well
